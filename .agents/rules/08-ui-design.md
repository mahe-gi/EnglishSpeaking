# UI & UX Design Rules
<!-- description: Apply when creating, styling, or modifying mobile screens, web pages, components, and design tokens. -->

## Visual Direction
- Minimal, quiet, clean, typographic, spacious, focused.
- Typography: Inter (weights 400, 500, 600). Wordmark-only brand ("Ntalo").
- One dominant action per screen. Avoid visual clutter, decorative gradients, or arbitrary cards.
- Prefer spacing, alignment, and dividers over nested card boxes and heavy shadows.

## Design Tokens
- Use defined tokens: `background`, `surface`, `textPrimary`, `textSecondary`, `border`, `accent`, `success`, `warning`, `danger`.
- Never hardcode random hex colors in component templates.

## Micro-copy
- Concise, clear, and actionable. Never explain obvious actions with verbose paragraphs.
